# Landing page (local)
   
This folder contains a copy of `index.html` (the landing page) and a small Python script to serve it locally.

How to run:

1. Open a terminal and change directory:

```bash 
cd "C:\Users\91963\Desktop\kalpesh\landing"
```

2. Run the server (requires Python 3):

```bash
python server.py
```

This will open http://127.0.0.1:8000 in your browser. You can pass a different port:

```bash
python server.py 3000
```
